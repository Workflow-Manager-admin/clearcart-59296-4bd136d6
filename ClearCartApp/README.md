# ClearCart iOS Frontend

This is the main iOS container for the ClearCart frontend, using SwiftUI.

## Features
- User Registration and Login
- Browse Restaurants and Stores
- Order Placement
- Payment Integration (UI only; gateway backend required)
- Order Tracking (Sample data)
- Transparent Pricing
- Minimalistic, clean layout

## Color Scheme
- Primary: #606060
- Secondary: #000000
- Accent: #ffffff

## Structure
- ClearCartApp.swift: Entry point
- RootContainerView.swift: App navigation & container
- Theme.swift: Color palette and theme config
- BrowseView.swift: Restaurant browse and menu view
- OrdersView.swift: Cart, order summary/tracking
- ProfileView.swift: User account & profile
- AuthView.swift: Login/register UI

See comments in code for extension points.
